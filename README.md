# Social Media Addiction Analysis Dashboard

## Project Overview

This project is an Excel-based analytical dashboard focused on studying social media addiction patterns among students. The workbook contains pivot-table-based analysis, summary statistics, and interactive visualizations that help identify behavioral trends related to social media usage, sleep patterns, relationship status, conflicts, and addiction scores.

The dashboard transforms raw survey data into meaningful insights using Microsoft Excel.

---

# Objectives

The primary objectives of this project are:

* Analyze social media addiction levels among students
* Compare addiction scores based on gender and relationship status
* Study the impact of social media usage on sleep patterns
* Understand behavioral conflicts caused by social media
* Create an interactive and visually understandable dashboard
* Practice data analysis and dashboard design using Excel

---

# Workbook Structure

## 1. Sheet1

Contains pivot-table-based analysis and summary statistics.

### Analysis Included

#### Gender-wise Addiction Score

Compares total addiction scores between:

* Male
* Female

#### Relationship Status Analysis

Analyzes social media addiction based on:

* Single
* In Relationship
* Complicated

#### Average Daily Usage Hours

Displays average time spent daily on social media.

#### Average Sleep Hours Per Night

Analyzes sleep duration patterns among students.

#### Student Count Analysis

Shows the count of students included in the dataset.
